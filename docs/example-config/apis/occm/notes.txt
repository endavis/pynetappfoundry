OCCM (Console agent) specs.

Runtime does not read this directory. Calls to a Console agent go through
ConsoleAgentClient, which uses the Console spec
(tools/console_openapi/generated/console_openapi.yaml) and the Console account
(see apis/console/notes.txt). Nothing under <config>/apis/occm/ is needed.

The files here (all.json, openapi3.json) only feed code generation. Refresh
them with
  doit fetch_spec --api=occm --host=<connector> --username=<email> --password=<password>
  doit convert_specs --api=occm
  doit generate_models --api=occm

The username is the Console login email.

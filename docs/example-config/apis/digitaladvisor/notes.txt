Active IQ Digital Advisor API setup. See docs/usage/digital-advisor-api.md.

1. Credential: in the Digital Advisor portal, create a personal access token
   (valid 1-90 days), or log in and take the access/refresh token pair
   (refreshing works for 90 days from the portal login).

2. Settings: create <config>/apis/digitaladvisor/digitaladvisorapi.toml with a
   [general] section (see the example next to this file). Store the credential with
     nf config set-credential --setting digitaladvisorapi.personal_access_token
   or
     nf config set-credential --setting digitaladvisorapi.refresh_token

3. Schema (optional, no credentials needed):
     nf config download-schema
   It writes <config>/apis/digitaladvisor/schema.json.

4. Check:
     nf config validate

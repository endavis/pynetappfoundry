DII (Data Infrastructure Insights) API setup. See docs/getting-started/configuration.md.

1. Settings: create <config>/apis/dii/diiapi.toml with a [general] section
   (base_url, base_api_path).

2. Token: store the API access token with
     nf config set-credential --setting diiapi.api_ro_token
   or per tenant with
     nf config set-credential --type cloudinsights --name <tenant> --user <label>
   The client sends it as the header X-CloudInsights-ApiKey.

3. Spec: copy all.json from this directory into <config>/apis/dii/, or refresh
   it with
     doit fetch_spec --api=dii --host=<tenant> --api-key=<token>
   doit fetch_spec sanitizes the spec; no manual edits are needed.

4. Check:
     nf config validate
     nf config show -s cloudinsights

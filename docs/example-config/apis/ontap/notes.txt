ONTAP REST API setup. See docs/getting-started/configuration.md.

Spec:
  Copy all.json from this directory into <config>/apis/ontap/ (the release tag
  you installed has the spec that matches the generated models).

Refresh the spec with:
  doit fetch_spec --api=ontap --host=<cluster> --username=<user> --password=<password>
  doit convert_specs --api=ontap     # converts all.json into openapi3.json
  doit generate_models --api=ontap

doit fetch_spec sanitizes the spec; no manual edits are needed.

Auth is HTTP Basic: the client sends the cluster user and password in an
Authorization header on every request.
